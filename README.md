# PicaLab
Picalab adalah aplikasi web pengolahan citra digital interaktif berbasis Python yang dikembangkan menggunakan Streamlit dan OpenCV. Dirancang sebagai proyek praktikum mata kuliah Pengolahan Citra, aplikasi ini mengombinasikan antarmuka yang ramah pengguna dengan implementasi algoritma pengolahan citra tingkat lanjut secara real-time.
